# 独立会话可读性检查

日期：2026-10-26。版本：v0.1 格式基线，未包含后续 v0.2 评分功能。方式：向一个未提供原始聊天历史的独立 AI 会话，仅提供 `AGENTS.example.md` 的位置和“磁盘”主题，要求按入口查找经验并回答适用条件、执行方式、验收及局限。禁止执行清理脚本。

读取者实际选择了四个文件：

1. [接入说明](../AGENTS.example.md)
2. [主题入口](../memory/INDEX.md)
3. [磁盘索引](../memory/disk/INDEX.md)
4. [DISK-001](../memory/disk/DISK-001.md)

其回答正确指出：适用于 Windows 默认 pip/npm 缓存；先预览后执行；需要检查删除结果、空间和缓存工具；原验收不覆盖所有应用，公开摘要不能独立复现历史执行或证明普遍收益。

结果：上述单个案例的路由与含义理解检查通过。本次使用同一服务下的独立 AI 会话，未进行不同厂商或多模型对照，也未执行清理、测量 token 节省或验证新机器上的操作效果。
